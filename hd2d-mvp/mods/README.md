# 数据包（mod）怎么写

数据包只写 JSON，用来加城、加路、加势力、加武将，或者改原版城和武将的开局状态。不能写脚本，不能改规则公式，不需要跑任何美术流水线。

一个数据包是 `mods/` 下的一个文件夹，文件夹名就是包的 id。范本见 [`sample-cities/`](sample-cities/)。

```
mods/<包名>/
  pack.json        必需
  cities.json      新增城，或改原版城的开局数值
  roads.json       新增道路
  factions.json    新增势力
  officers.json    新增武将，或改原版武将的开局数值
```

写完先校验，再登记：

```bash
node hd2d-mvp/tools/check_pack.mjs hd2d-mvp/mods/<包名>
node hd2d-mvp/tools/check_pack.mjs --all --index
```

`--index` 会重写 `mods/index.json`，标题画面的「数据包」列表读的就是它。网页版也可以直接打开 `?pack=<包名>`。

数据包还在探索阶段，0.3.7 起标题画面默认不显示「数据包」按钮：地址带 `?packs` 时才显示；已经装着包时也显示，好换回本体。

桌面版会读「文稿/Three Kingdoms HD-2D/mods/」里的包，但按钮隐藏期间桌面版选不到它们。安卓版只能用随游戏发布的包。

## 引用：写名字或编号

凡是指向一座城、一名武将、一个势力的地方，写名字（`"洛阳"`、`"关羽"`、`"刘备"`）或编号都行。原版势力的名字就是开局君主的名字：董卓 0、袁绍 1、曹操 2、孙策 3、刘备 4、刘璋 5、马腾 6。

新城、新武将、新势力按出现的先后编号：城从 30 起，武将从 237 起，势力从 8 起（7 是"无主"，留空）。

名字 1–12 个字，不能含 `< > & " ' \` \\`。

原版的城一律写原版的名字（`"幽州"`、`"荆州"`、`"西平关"`），不管玩家把「☰ 系统 → 地名」设成原版还是考据：那个开关只换显示的名字（幽州显示成北平），包照样按原版名读，两种设置下都能装。新城可以叫考据名里的名字（比如再加一座「寿春」）；这时原版那座城在考据设置下也仍显示原版名（扬州），不会出现两座同名的城。

## pack.json

```json
{ "id": "my-pack", "name": "我的数据包", "version": "1.0.0", "author": "作者", "game": 1, "description": "一句话说明" }
```

- `id`：和文件夹名相同，小写字母、数字和 `-`。
- `version`：`主.次` 或 `主.次.修`。存档记下包的版本，**主版本号相同**的存档才能读。只追加内容时升次版本号；删改了城、武将或道路，旧存档会对不上，就升主版本号。
- `game`：数据包格式版本，现在是 `1`。
- `regions`：可选，用到哪些官方扩展地块（目前只有 `japan`，见下文）。

## cities.json

```json
{
  "add": [
    { "name": "会稽", "seat": "山阴（绍兴）", "lon": 120.48, "lat": 29.85, "tier": "county", "like": "建安",
      "calamity": "flood", "faction": "孙策", "gold": 180, "rice": 260 }
  ],
  "edit": [
    { "city": "洛阳", "gold": 900, "faction": "曹操" }
  ]
}
```

新城（`add`）：

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 城名，不能与已有的城重名 |
| `lon`、`lat` | 是 | 治所经纬度。要落在原版沙盘（东经 97.5–125、北纬 20–43）或声明的地块的陆地上，城的整块占地不能压到海、河、湖；和别的城至少隔 0.9 个格（约 1 个纬度）。城下的树和村落会自动让开；压到沙盘上的山脉时 `check_pack.mjs` 会提示，最好挪到平地上 |
| `tier` | 是 | 模型：`capital` 都城、`major` 州治大城、`county` 郡城、`pass` 关隘 |
| `style` | 否 | 城池模型的样式：`han` 汉式（默认）、`japan` 日本战国式、`korea` 朝鲜王朝式。只换外观，占地和规则都按 `tier`；原版城不能改 |
| `like` | 是 | 借用哪座**原版**城的战争地图、布阵和村庄。开战时就在那座城的战场上打 |
| `seat` | 否 | 治所说明 |
| `faction` | 否 | 开局归属；不写就是无主。有归属的城必须有武将，无主的城不能有武将 |
| `calamity` | 否 | `drought` 旱灾城、`flood` 水灾城，不写就两样都不遭 |
| `gold` `rice` `pop` `land` `industry` `disaster` `gov` `reserve` `treasure` | 否 | 开局数值，不写就取 `like` 那座城的 |
| `facilities` `rice_rate` `shop` `field_shop` `ai_shop` | 否 | 设施、米价、商店，不写就取 `like` 的 |
| `search` | 否 | 在这座城搜索能找到的武将，按顺序 |

改原版城（`edit`）：用 `city` 指明哪座，只能改 `faction` 和上面那些开局数值。**不能改经纬度**：原版城的城垫和周围的田是画进沙盘地面的，城一挪，旧的城垫还留在原地。

## roads.json

```json
[["会稽", "建业"], ["会稽", "建安"]]
```

道路都是双向的。可以给原版城加路，不能删原版的路。全图所有城必须连成一片。跨海的路会自动画成虚线航路。战略地图平时不画路：点「道路」显示全部道路，选中一座城时显示它通往邻城的路。

## factions.json

```json
[
  { "name": "越", "ruler": "勾践", "like": "孙策", "colors": { "flag": "#20a088", "land": "#26b89a" },
    "succession": ["范蠡"], "join": [], "prefer": ["西施"] }
]
```

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 势力名（游戏里平时显示君主的名字，势力灭亡后才用它） |
| `ruler` | 是 | 君主：开局必须在本势力的某座城里，不能是别的势力的君主 |
| `like` | 是 | 借用哪个原版势力的 AI 性格（进攻与内政的倾向、调兵的门槛） |
| `colors` | 是 | `flag` 旗帜和名牌的颜色，`land` 领地染色的颜色，都写成 `#rrggbb` |
| `troops` | 否 | 白兵里这家士兵的外观，只换样子、不换规则：`soldier`（步兵）可写 `hillman` 山岳蛮兵、`ashigaru` 日本足轻，`cavalry`（骑兵）可写 `elephant` 南蛮战象、`steppe` 匈奴铁骑，例如 `{ "soldier": "ashigaru", "cavalry": "steppe" }`；没写的兵种照原版。武将自己也可以写 `troops`（见 officers.json），写了的兵种以武将的为准。这些外观的图只在开源仓库里，桌面版和安卓版的安装包不带，在那里照原版兵种显示 |
| `succession` | 否 | 君主死后优先继位的人，按顺序 |
| `join` | 否 | 到了登场年份会自动来君主所在城出仕的武将，按顺序 |
| `prefer` | 否 | 偏爱本势力的武将：被本势力搜索到时更容易出仕 |

最多 8 个新势力。玩家可以在标题画面选新势力开局。

## officers.json

```json
{
  "add": [
    { "name": "勾践", "like": "孙策", "city": "会稽", "war": 80, "int": 75, "virtue": 85, "loyalty": 100 },
    { "name": "西施", "like": "陆逊", "city": "会稽", "appear": "search", "year": 190 },
    { "name": "伍子胥", "like": "太史慈", "appear": "join", "faction": "越", "year": 191 }
  ],
  "edit": [
    { "officer": "关羽", "war": 100 },
    { "officer": "张飞", "city": "建安" }
  ]
}
```

新武将（`add`）：

| 字段 | 必填 | 说明 |
|---|---|---|
| `name` | 是 | 不能与已有武将重名 |
| `like` | 是 | 借用哪个**原版**武将的整套美术：立绘、半身像、表情、单挑和行军的像素图。同一张脸会出现在两个人身上，这是只写数据的代价 |
| `look` | 否 | 女将外观，只换战场上的样子：`f-spear` 女将·枪、`f-blade` 女将·刀、`f-sword` 女将·剑。白兵立像、单挑动作和战争地图行军都换成这套，立绘、表情和数值仍取 `like` 的。单挑里的出招按外观画的兵器走，最好把 `weapon` 写成同一类（剑 0–7、刀 8–15、枪 16–23），不一致时 `check_pack.mjs` 会提示。这些图只在开源仓库里，桌面版和安卓版的安装包不带，在那里照 `like` 的样子显示 |
| `troops` | 否 | 他带的兵在白兵里的外观，写法同 factions.json 的 `troops`，例如 `{ "cavalry": "elephant" }`。跟着武将走，不管他在哪个势力：写了的兵种用他的，没写的用所在势力的，势力也没写就照原版。同样只换样子、不换规则，安装包里照原版兵种显示 |
| `appear` | 否 | `initial` 开局就在城中（默认）、`search` 到年份后在城里搜索出现、`join` 到年份后自动来势力君主所在城出仕 |
| `city` | `initial`、`search` 必填 | 所在城 |
| `faction` | `join` 必填 | 投奔哪个势力 |
| `year` | 否 | 登场年，默认 189；`initial` 只能是 189 |
| `hp` `war` `int` `loyalty` `virtue` `exp` `soldiers` `weapon` `armor` `level` `army` `death` | 否 | 不写就取 `like` 那个武将的。`army` 是兵种：平、山、水；`death` 是寿终的年份 |

改原版武将（`edit`）：用 `officer` 指明是谁，能改数值，也能写 `troops` 给他的兵换外观（例如让原版某员南方武将带战象）；`city` 只能挪开局就在城中的武将。不能改登场年份，也不能删武将。

## 官方扩展地块

原版沙盘只画了中国。周边的地形由本体作者做成官方扩展地块，数据包在 `pack.json` 里写 `"regions": ["japan"]` 就能在上面摆城。只有已开放的地块能用，`check_pack.mjs` 会告诉你哪些可用。地块以外的地方不能放城。

| 地块 | 范围 | 包括 |
|---|---|---|
| `japan` | 东经 125–146°，北纬 20–46°；另加原版上方北纬 43–46° 的一条 | 朝鲜半岛、日本全境（含北海道）、满洲东部和沿海；上方一条是蒙古高原南缘、大兴安岭 |

装了 `japan` 的包，桌子向右、向上都加宽，仍是一个矩形。日本的河只有石狩川、利根川、最上川（地图数据里只有这三条），琵琶湖和兴凯湖按原版画湖的办法画成椭圆。

日本的岛窄，城的占地一圈都不能压到海、河、湖，真实坐标的城多半要往内陆挪零点几度，按 `check_pack.mjs` 的提示挪。

## 存档

装了数据包的存档单独存放，和本体的存档互不影响。换了别的包，或者包的主版本号变了，读档界面会说明那份存档为什么读不了。
