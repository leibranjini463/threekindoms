1先改设置：难度直接降两档

开局画面上有三个选项，选错任何一个，新手都会被电脑按在地上摩擦。照下面选：

  • 难度选 LEVEL 1。一共 LEVEL 1 / 2 / 3 三档，先从最低的打起，熟悉了再往上加。
  • 电脑 AI 选「原版」，千万别选「好战」。「好战」是重制版新加的模式，电脑每个月都会征兵补兵、内政做得又快又勤，凶得多。同是 LEVEL 1，选了好战照样打不过——很多人就栽在这。
  • 把「秘技」开关打开。这是原版留下的彩蛋，只在 LEVEL 1 可用：打开后，你君主所在的城，金、米、人口、土地、后备兵全部 9999，产业 999，防灾、统治、宝全部 99。等于大本营直接拉满，第一次玩就开着，先爽一把把系统摸熟，不丢人。
💡 注意：秘技只加满君主所在的那一座城。其他城池该穷还是穷，靠后面讲的「输送」从大本营调钱粮、用后备兵补给。

3每月在干什么：指令分工表

这游戏的节奏是按月回合：每个月你能下达的命令数量有限（命令书随你城池变多而增长），所以每个武将每月干什么，要分工明确，别乱点。

活儿派谁去作用
开垦政治高的涨土地 → 每月米收入变多
商业政治高的涨产业 → 每月金收入变多
搜查智力高的在城里翻出隐藏武将、宝物和钱粮（本作捡人的主要方式！）
登用君主本人 / 魅力高的把搜出来的人、在野的人招到麾下
征兵谁都行把后备兵编成正式兵。别贪多，见下方警告
训练武力高的涨士气，打仗时兵更扛揍
输送谁都行城与城之间调运金、米、兵，大本营养前线的关键
⚠️ 兵是要吃米的。征兵一时爽，米不够吃的时候士兵哗变、逃亡，比打败仗还惨。原则：先看米再征兵，兵力够守城 + 打一座弱城就行。

记住一句话：武将数量就是这游戏的命根子。前期最重要的事不是打仗，是搜查捡人、登用招人。人多，每月能干的活就多，滚雪球就开始了。

4刘璋爽局发展路线（四步走）

刘璋手下本来就不弱：汉中有严颜（武 86）、张任（武 84）守北门，成都有雷铜（武 82）、黄权（智 78），云南有法正（智 92）、孟达，涪陵有张松（智 90）。再按下面四步走，这局就稳了。

第一步：成都大本营，搜查补员

秘技已经把成都（刘璋所在城）拉满了，钱粮不愁。开局头几个月别打仗，全员干内政 + 搜查：

  • 成都搜查 → 能翻出 李严（武 82 / 智 75，能打能算）、董允、杨仪，搜到就登用。
  • 涪陵搜查 → 蒋琬（智 90）、费祎（智 85）、向宠、张翼，全是顶级文官，内政和以后打仗都靠他们。
  • 云南搜查 → 鄂焕（武 85），南边的前锋就有了。
  • 政治高的继续开垦、商业，把成都周边几座城的收入也拉起来；多余的钱粮用「输送」往前线城送。
第二步：先吃永昌，南边落袋为安

永昌是无主空城，就在云南南边，不用打，派个武将带点兵走过去就占了。占下之后在永昌搜查 → 孟获（武 87）、兀突骨（武 80）两位南蛮猛将直接入伙。至此你有 5 座城，整个西南后方彻底安稳，谁也威胁不到你。

第三步：东进荆州，抢诸葛亮

攒够兵之后，从涪陵 / 成都向东，目标 荆州（无主空城，先到先得，要抢在别人前面）。荆州的搜查名单是全游戏最豪华的：诸葛亮（智 99）、徐庶（智 96）、马良（智 94）、周仓（武 84）。把诸葛亮招到手，你的军师位就毕业了。顺路把新野、长沙、衡阳、零陵这些南部空城一并收了，半壁江山到手。

第四步：汉中北伐，直取长安

后方稳固、人也齐了，从汉中出兵北上打长安（董卓的地盘）。严颜、张任就是为这一步准备的。打之前记得：兵力至少是守军的 1.5 倍、从成都输送足够的米过去、出征前先存档。拿下长安，洛阳就在眼前，统一只是时间问题。

5打仗速成：只记五条

  1. 只打弱的。空城、叛乱城、兵比你少的城优先；对方兵力 ×1.5 以下的仗，新手不要接。
  2. 出征前先存档。打输了读档重来，天经地义。这游戏的存档位就是给你这么用的。
  3. 野战先围后打。在战场地图上把部队展开、占住地形再接敌，别让单个武将冲进人堆。
  4. 白兵战挑软柿子。让我方武力高的，先打对方武力低的，以强吃弱、攒经验升级；别一上来就硬碰对方主将。
  5. 猛将就单挑。武力 85+ 的将（严颜、孟获、张任这一档）单挑赢面很大，一场挑翻对方一员将，对面士气直接崩。反过来，对方有吕布这种怪物时，绕开他，别送。
💡 实在打不过的仗可以撤：战斗里用「战场中断」先退出来，进度能从标题画面恢复（只能恢复一次，见下节）。保住武将比保住一座城重要——城丢了能再打，人没了就真没了。

6存档与刷新须知（重要！）

  • 存档存在你自己的浏览器里（localStorage），一共 8 个存档位，不用注册、不用联网。
  • 刷新页面 = 回到标题画面。没存档的进度，刷新一下就没了。养成习惯：打大仗前存、出远门前存、每个月顺手存。
  • 战斗中途想停：用「战场中断」退出，之后在标题画面可以接着打——但只能恢复一次，恢复后那个中断点就没了。
  • 存档是按网址分开存的：换一个链接打开游戏，看不到之前的存档。认准你现在玩的这个地址，别换来换去。
  • 不要用无痕 / 隐私模式玩，窗口一关，存档全清。
